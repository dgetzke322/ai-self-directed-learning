# Test Product Vision: Team Task Tracker

## Problem
Engineering teams struggle to track who is working on what without interrupting context. Slack messages get lost, email threads are too slow, and spreadsheets don't update in real time.

## Vision
A lightweight task board integrated with Slack that lets teams see what everyone is doing, update status asynchronously, and get notified of blockers without leaving their workflow.

## Core Requirements
- Task creation with assignee, due date, status (backlog, in-progress, blocked, done)
- Slack integration: create tasks from /commands, get status updates in Slack
- Real-time status sync (when someone updates a task, team sees it immediately)
- Blocker notifications (team gets alerted when a task is blocked)
- V1 scope: Slack only, single workspace, max 20 active tasks

## Success Metrics
- Adoption: 50% of team using board within 2 weeks
- Engagement: average of 10 status updates per day
- Time saved: team reports 10+ hours/week saved from reduced interruptions
